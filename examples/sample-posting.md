# Senior Front End Engineer — Acme (Remote, Spain)

**About Acme**

Acme builds scheduling software for clinics. 60 people, product-led, profitable,
fully remote across Europe since 2019. You will join a team of six engineers
working on the patient-facing booking flow.

**What you'll do**

- Own the front end of the booking flow, from design handoff to production.
- Extend our design system and keep it the default way to build UI.
- Hold the accessibility bar: WCAG 2.2 AA, keyboard and screen-reader tested.
- Keep the booking flow fast on mid-range mobile; we treat performance as a feature.
- Review code, pair with designers, and mentor two mid-level engineers.

**What we need**

- 5+ years building production web applications with React and TypeScript.
- Strong HTML, CSS and responsive layout skills.
- Experience with design systems or shared component libraries.
- Accessibility: you have shipped WCAG-compliant interfaces, not just read about them.
- Testing: unit and end-to-end, and the judgement to know which is worth writing.
- Excellent written English; we are async-first.

**Nice to have**

- GraphQL (we are migrating from REST).
- Next.js App Router.
- Experience in regulated or health products.

**What we offer**

- Fully remote within Europe, or hybrid from our Madrid office (1 day/week).
- EUR 78,000–92,000 depending on seniority.
- 30 days holiday, learning budget, quarterly on-sites.

Acme is an equal opportunity employer. We will never ask for a security
clearance; all work is on unclassified systems.
